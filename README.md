# LandLearnApp — 시작 가이드

토지투자 **입문·실전 앱 1.0** (ServerTest 홈피와 **별개**)

## 바로 실행

1. **`로컬미리보기.bat`** 더블클릭
2. 브라우저가 `http://localhost:8770/` 로 열립니다
3. **1장 시작** → 퀴즈 **B** 선택 → **완료** → 로드맵에 진행률 반영

> 서버가 이미 켜져 있으면 bat을 다시 실행하지 마세요. 브라우저에서 주소만 입력하면 됩니다.

## Cursor에서 작업

1. **File → Open Folder** → `LandLearnApp` 선택
2. AI에게: **「ServerTest 수정하지 마. LandLearnApp만」**
